# OSE — трекер ходів підземелля (PWA)

Трекер ходів підземелля для Old-School Essentials: 1 клітинка = 1 хід (10 хв),
перевірки блукаючих монстрів, нагадування про відпочинок, таймери світла й чарів.
Працює офлайн і встановлюється на телефон як застосунок.

## Як встановити

- **iPhone / iPad:** відкрийте адресу в Safari → «Поділитися» → «На початковий екран».
- **Android (Chrome):** у самому застосунку з'явиться кнопка «Встановити застосунок» (або меню ⋮ → «Встановити»).
- **Комп'ютер (Chrome / Edge):** значок встановлення в рядку адреси.

## Важливо

- Дані (ходи, таймери, нотатки) зберігаються лише на цьому пристрої. Для перенесення:
  ⚙ Налаштування → «Скопіювати стан» на одному пристрої → «Відновити» на іншому.
- Після зміни будь-яких файлів збільште `VERSION` у `sw.js` (наприклад, `osedtt-v2`) —
  інакше встановлені копії продовжать показувати стару версію з кешу.
